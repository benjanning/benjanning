# Current portfolio previews

README images load the central portfolio's stable featured-image URLs. The site generator copies genuine, approved source-release visuals to those URLs and validates their bytes against versioned assets. This lets the profile follow approved portfolio image refreshes without copying screenshots manually. GitHub's image cache may refresh later than the website.

For exact source revisions, verification runs, image hashes and source-owned provenance, see the [portfolio evidence lock](https://github.com/benjanning/projects/blob/main/supporting-site-files/source-lock.json) and each linked case study. The hotel image contains illustrative licensed photography, credited in the [hotel source](https://github.com/benjanning/cork-city-hotel/blob/main/public/credits.html). All application records are synthetic; charts show actual supplied data and measured results. Historical local image files remain preserved in Git history and the assets directory.
